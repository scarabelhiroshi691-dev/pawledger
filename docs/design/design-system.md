# 仪表盘设计系统 v1

设计基准：[dashboard-concept-v1.png](dashboard-concept-v1.png)

- 主画布使用纯白 `#ffffff`，侧栏使用冷灰蓝 `#f4f8fc`。
- 主文字使用深海军蓝 `#102542`，安全财务操作使用青绿色 `#008c83`。
- 待处理使用琥珀色 `#b7791f`，退款和错误只使用红色 `#c83232`。
- 页面标题 30px/700；分区标题 18px/700；正文和表格 14px/400-600。
- 金额使用等宽数字特性 `font-variant-numeric: tabular-nums`。
- 侧栏宽 224px；主内容最大宽度 1440px；间距以 4px 为基线。
- 控件圆角 8px，主要分区 10px，普通分区只用 1px 边框、不用阴影。
- 主按钮为青绿实底；表格表头为冷灰蓝底；对账成功使用线性圆形勾图标。
