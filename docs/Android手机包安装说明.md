# 爪账 Android 店员端安装说明

## 安装要求

- Android 8.0 或更高版本。
- 手机与运行爪账 1.3 的 Windows 电脑连接同一个可信门店 Wi-Fi。
- Windows 网络类型应为“专用网络”。

## 第一次连接

1. 把 `PawLedger-Staff-Android-1.3.0.apk` 发到手机并点击安装。若系统拦截，只允许当前使用的文件管理器“安装未知应用”，安装后可关闭该授权。
2. 在 Windows 电脑上右键运行“配置手机端访问.cmd”，再双击“启动爪账.cmd”。
3. 登录电脑端，打开“管理”，找到类似 `http://192.168.1.23:5088` 的手机访问地址。
4. 打开“爪账店员端”，输入完整地址或只输入 `192.168.1.23`；未填写端口时自动使用 5088。
5. 使用店员账号登录。顶部“刷新”用于重新加载，“换电脑”用于修改地址。

## 连不上时

- 确认电脑上的爪账仍在运行。
- 确认手机没有切换到访客 Wi-Fi、移动数据或另一个路由器。
- 重新运行“配置手机端访问.cmd”，并核对 Windows 当前仍是“专用网络”。
- 电脑 IP 变化后，在 App 顶部选择“换电脑”，填写电脑端最新显示的地址。

## 安全边界

App 不复制主数据库，也不直接保存店员密码；登录 Cookie 由 Android WebView 保存在手机应用空间。门店局域网 HTTP 没有传输加密，只应在可信 Wi-Fi 中使用。本包是内部侧载测试签名，不用于应用商店发布；正式对外发布需要保管独立签名密钥并重新签名。
