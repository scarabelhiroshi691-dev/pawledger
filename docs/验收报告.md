# 爪账 1.3 验收报告

- 目标环境：Windows x64，单店单机，电脑端可断网运行；手机店员端使用门店局域网。
- 核心链路：首次设置 → 员工账号 → 会员/宠物 → 本金与赠送金充值 → 美容师/服务 → 美容结算/团购履约 → 商品销售 → 交接班 → 日结核对 → 审计与备份。
- 会员账务：本金与赠送金分账；消费、部分退款和充值撤销使用不可删除的反向流水，余额与流水累计可逐卡核对。
- 美容业务：完成工单必须记录实际美容师，日结按美容师汇总完成单数和金额。
- 员工权限：管理员与店员使用独立账号；店员可登记团购履约，但不能访问团购结算、员工账号、交易总表、日结、审计和备份；账号可停用，且不能停用最后一个管理员。
- 钱箱实测：开班备用金 300 元，登记现金支出 35.50 元后系统应有 264.50 元；实点 260 元关班，系统正确记录差额 -4.50 元。
- 支出与日结：支出记录分类、方式、收款方、用途和操作人；日结展示支出总额与现金支出，并提示未关闭班次。
- 审计：关键业务操作按时间、操作人、对象和详情只读展示，页面不提供删除。
- 团购闭环：实测店员登记美团订单、实际美容师、核销 128 元和预计到账 108.80 元；重复订单被阻止；管理员确认实际到账 107.50 元并登记部分退款 28 元，日结和美容师净业绩均正确反映。
- 外部平台：本版本不调用美团接口；真实验券在美团官方商家端完成，爪账只记录店内履约与对账。
- 自动化测试：领域测试 9 项、Web/数据库服务测试 9 项，合计 18 项全部通过。
- 浏览器验收：390×844 手机和 1440×900 电脑视口完成角色切换、团购登记、防重、权限拦截、到账、退款、日结和审计流程；最终页面控制台 0 错误。
- 数据保护：SQLite WAL、同步级别 FULL、支付请求幂等键、余额并发版本、不可删除流水、在线一致性备份、离线恢复前自动备份。
- 已知范围：商品收银每单一种商品；不连接云端、短信、支付平台、多店同步或收银硬件。
