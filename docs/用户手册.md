# 爪账 1.3 用户手册

爪账是面向单店、单台 Windows 电脑的宠物店管理系统。会员、账务和业务数据保存在店内电脑；电脑端可断网使用，手机店员端通过同一门店网络连接电脑。

## 第一次使用

1. 双击“启动爪账.cmd”。浏览器会自动打开。
2. 首次启动创建店长账号。密码至少 8 位并包含数字。
3. 在“员工账号”给每位店员建立独立账号；在“员工与服务”设置美容师和服务项目。
4. 在“会员与宠物”新建会员和宠物，之后可做会员充值。

闭店时先完成备份，再双击“关闭爪账.cmd”。仅关闭浏览器不会关闭后台程序；重复双击启动器会直接打开已有实例，不会重复启动。

## 会员卡规则

- 实收金额进入“本金”，赠送金额进入“赠送金”，两类余额分账记录。
- 消费依次扣赠送金、本金；余额不足的部分使用现金、微信、支付宝等外部收款。
- 部分退款依次退外部收款、本金、赠送金；退回卡内的金额生成独立反向流水。
- 流水不可删除。充值录错只能撤销；已消费的充值需先处理相关消费退款。
- “日结对账”应显示“核对通过”后再闭店。

## 美容和商品

- 美容结算必须选择实际完成工作的美容师，业绩显示在日结页。
- 商品建档可填写期初库存；销售自动扣库存。库存不足时不能收银。
- 首版商品收银每单支持一种商品，可连续开单。

## 美团团购

1. 店员先在美团官方商家端完成真实验券核销。
2. 回到爪账“团购登记”，填写完整美团订单号、套餐、核销金额和预计到账；美容类套餐必须选择实际工作的美容师。
3. 同一美团订单号只能登记一次，重复提交不会再次计入。
4. 管理员按美团结算账单进入“团购结算对账”，填写实际到账金额；与预计金额的差额会写入审计记录。
5. 平台发生退款时，由管理员登记退款金额和原因；允许分次退款，但累计不能超过原核销金额。
6. 日结页分别显示当日团购核销、预计结算、退款，以及团购来源的美容师净业绩。

团购登记不是美团验券工具，不读取完整券码，也不会改变顾客团购券状态。不要在爪账中登记尚未在美团商家端成功核销的券；同一笔服务不要再另开店内美容结算单，以免业绩重复。

## 店员账号与权限

- 管理员可以建立管理员或店员账号，并随时停用/启用登录。
- 店员可以办理日常会员、充值、美容、商品和交接班业务，不能进入员工账号、退款总表、日结、审计和备份页面。
- 每位员工必须使用自己的账号，系统会在充值、退款、开关班和支出等关键操作中记录操作人。
- 系统不允许停用当前登录账号，也不允许停用最后一个可登录管理员。

## 交接班与支出

1. 开门或换班时进入“管理 → 交接班与支出”，清点钱箱并填写开班备用金。
2. 班次中发生现金或电子支付支出时，登记分类、金额、支付方式、收款方和用途。现金支出必须有正在进行的班次。
3. 系统应有现金 = 开班备用金 + 本班现金充值 + 本班现金销售 − 本班现金支出。
4. 关班时输入实际现金；差额不为零时填写说明并交店长复核。
5. 店长在“日结对账”确认无未关闭班次，并在“操作审计”核查异常操作。

## 手机店员端

1. 在 Android 8.0 或更高版本手机安装 `PawLedger-Staff-Android-1.3.0.apk`；首次侧载时按系统提示允许当前文件管理器安装未知应用。
2. 电脑和手机连接同一个门店 Wi-Fi，并把 Windows 网络类型设置为“专用网络”。
3. 在电脑上右键运行“配置手机端访问.cmd”。它只开放专用网络的 TCP 5088 端口，然后正常启动爪账。
4. 在电脑端“管理”页查看手机访问地址。打开“爪账店员端”，输入其中的 IP 地址；省略端口时 App 会自动使用 5088。
5. 店员使用自己的账号登录。App 支持会员、充值、美容、商品、团购履约和交接班；顶部可刷新或更换店内电脑。

App 是店内局域网客户端，主数据库仍只在 Windows 电脑。手机离开门店网络或电脑关闭后不能提交业务；电脑端离线业务不受影响。当前内测包不承诺摄像头扫码，会员号和商品条码可手动输入。

## 外部平台边界

- 本版本不调用美团接口，店内核心业务不依赖互联网。
- 美团官方商家端负责验券；爪账负责本店的履约人、应收、到账、退款和审计账。
- 将来取得企业或服务商开放平台权限后，才考虑自动拉取和核销；在此之前不采用抓包、模拟登录或网页自动点击等高风险方案。

## 备份与恢复

- 每日闭店后到“备份与恢复”点击“立即备份”。备份会自动做完整性检查。
- 定期把 backups 文件夹复制到 U 盘或另一块硬盘。
- 恢复前先关闭爪账，再右键 PowerShell 运行 `恢复备份.ps1 -BackupFile "备份文件完整路径"`。
- 恢复前的当前数据库会自动复制为 `pre-restore-日期时间.db`，便于回滚。

## 数据位置

本机存在 `D:\Codex` 时，默认数据目录为 `D:\Codex\PetShopData`；否则为 Windows 的 `C:\ProgramData\PawLedger`。也可通过环境变量 `PETSHOP_DATA_DIR` 指定。
