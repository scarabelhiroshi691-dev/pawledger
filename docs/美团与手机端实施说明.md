# 爪账手机店员端与美团团购实施说明

## 当前交付方式

- 手机端提供 Android 8.0+ 内部安装包，使用受控 WebView 连接 Windows 主机的响应式页面；电脑断网不影响本机业务。
- 店员先在美团官方商家端核销，再在爪账登记订单号、套餐、顾客/宠物、实际美容师、核销额和预计到账。
- 完整美团订单号设唯一约束，避免重复计入；爪账只保存可选的券码后四位，不保存完整券码。
- 管理员独占结算对账：确认实际到账、查看差额、登记部分退款；每一步都写入只读审计。
- 团购核销、预计到账、退款和美容师净业绩进入日结页。

## 为什么不做非官方直连

个人开发者没有目标接口权限时，抓包复制 Cookie、模拟商家 App、自动点击网页或保存账号密码都不适合作为正式产品：登录与风控可能随时失效，也会扩大账号和资金风险。当前方案把真实券状态留在官方商家端，把门店最需要控制的履约、员工归属和资金差额留在爪账。

## 将来正式接入的门槛

只有取得美团认可的企业/服务商资质、对应业务能力、商户与门店授权以及正式接口文档后，才进入自动接入。上线前至少需要完成签名与密钥托管、门店映射、回调验签、幂等、超时结果查询、限流、日志脱敏、沙箱与小额真实券验收，以及退款责任和撤销时限确认。

## 局域网与手机边界

- 发布版监听 TCP 5088，防火墙脚本只为 Windows“专用网络”开放端口。
- 每位店员使用自己的账号；手机必须连接可信门店 Wi-Fi。
- 当前 App 允许访问用户配置的门店 HTTP 主机，并把外部域名交给系统浏览器；证书错误不会被绕过。局域网 HTTP 不提供传输加密，只能在可信门店 Wi-Fi 使用。
- 当前内测包不承诺摄像头扫码；需要摄像头和公网远程使用时，应配置可信 HTTPS，并完成正式签名和更完整的移动端验收。
- 手机离开门店网络后不能提交业务；Windows 主机上的离线业务不受影响。
